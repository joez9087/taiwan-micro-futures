# 🇹🇼 台股微型臺指期貨 (微指期) 宏觀量化決策與推薦系統

一套專為**台股微型臺指期貨 (微指期, Micro TAIEX, TMF)** 量身打造的宏觀與多因子量化交易系統。系統結合了**台股加權指數季線趨勢 (60MA)**、**美股費城半導體 (^SOX) 隔夜領先動能**、**美元兌台幣匯率 (USD/TWD) 資金流**與 **自適應 ATR 波動率通道**，並針對期貨新手提供**每日明確推薦買點、推薦賣點、嚴格停損價、分批目標價**與**互動式 Web 決策儀表板**。

---

## 💡 為什麼選擇「微型臺指期貨」？（新手友善優勢）

1. **門檻低、小資首選**：一口原始保證金僅約 **新台幣 NT$18,000 元**。
2. **損益計算單純**：指數每跳動 **1 點 = 新台幣 10 元 (NT$10)**。
3. **無隔夜利息、稅費低廉**：期交稅僅契約金額之十萬分之二 (約 NT$5~9 / 口)，手續費約 NT$12~15 / 口。
4. **雙向交易靈活**：台股大盤上漲可做多，大跌時可隨時放空避險，不受現貨放空限制。

## 🚀 快速啟動指南

### 1. 執行一鍵量化回測與績效報告生成
```bash
python main.py
```
- 自動獲取最新台股加權指數、美股費半/納指與台幣匯率數據。
- 運算最新一期微台指推薦買賣點位。
- 產出 `TAIWAN_FUTURES_REPORT.md` 與 `data/taiwan_trades_log.csv`。

### 2. 開啟專屬 Web 視覺化決策儀表板
```bash
streamlit run app.py
```
瀏覽器將自動開啟互動式面板，包含：
1. **💡 今日微台指推薦買賣點操作指南**（即時買賣信號、進場區間、停損點與目標價）
2. **📈 策略回測研究中心**（資產曲線、水下回撤圖、歷年月度收益矩陣）
3. **📡 台股宏觀與跨市場雷達**（美股費半動能、台幣匯率資金流）
4. **🧮 微台指期貨新手損益計算機 ＆ 交易三大保命鐵律**
